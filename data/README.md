# Dados

O dataset principal é carregado diretamente de uma fonte pública durante a execução do projeto.

Fonte atual:

`https://storage.googleapis.com/download.tensorflow.org/data/creditcard.csv`

Arquivos brutos não são versionados neste diretório. Isso evita duplicar dados no Git e facilita a reprodução do projeto a partir da fonte original.

Caso o projeto passe a utilizar dados locais no futuro, esta pasta deverá conter apenas arquivos permitidos para versionamento e nunca dados pessoais ou credenciais.
